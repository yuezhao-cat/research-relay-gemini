# FeCoMn 写作红线（≤30 行；动笔前必读）
1. 不用破折号（——）和中文双引号；中文直译零全角冒号、分号。
2. 英文段落后附完整中文直译；修改稿先给原文，再给修改稿，改动处中英文都用「」标出。
3. 不写防御性语句：不写局限性声明、不用 tentatively / within the sampled models / without necessarily / consistent with 这类保守措辞，不写纯否定或自我辩解句。
4. 每句主语明确，不用需回找的 it / this / these；措辞平实。
5. 不写推测性的 possibly；不确定的列出来交赵月核。
6. 不写 T039 颗粒推迟过氧化（0.47–0.49 V、0.96 V）及"颗粒决定/保护轴向配体"。
7. 不写 dz² 靠近费米能级或作为原因；不写 Cdl、ECSA、比活性。
8. 不用 operating / operating-state、structural reorganization、energetic penalty、must。
9. 摘要不放机理对比（Mn–NC、FeCo–NC、无 OH 对照放正文）。
10. 红外只写界面物种随电位变化；不写"检测到 OOH*""确立缔合路径"（1215 cm⁻¹ 与 Nafion C–F 重叠，两片电极趋势相反）。
11. 术语：Mn single atoms（不写 Mn–N4 sites / dispersed Mn site）；an FeCoMn–NC。
12. Mn 回移写 toward the plane（O* 后 −0.10 Å 略过平面）。
13. 所有数字只取自 FACTS.md 中"已复核"项。
14. SI 图表在正文按升序首次引用；合并、移动、删段后重查编号。
15. Word 每次另存新版本，只高亮改动的词；Word 只在赵月明确要求时上传 GitHub。
16. 原始证据与多数意见冲突时，以原始证据为准。
