## 任务一：Levich 检查（极限电流偏高）

**背景。** 表 S3 中 1600 rpm 的极限电流为 FeCoMn–NC −6.33、FeCo–NC −4.77、Mn–NC −5.46、Pt/C −5.72 mA cm⁻²。按常用参数算，1600 rpm 的 Levich 理论值为 5.4 到 6.3 mA cm⁻²，常引用值约 5.7。Pt/C 与理论值吻合，说明面积（Pine E7R9，0.2472 cm²）和 O2 饱和没问题；FeCoMn–NC 偏高约 10%，需要查清来源。

**要做的。** 用 400、625、900、1225、1600、2025、2500 rpm 的原始 LSV（图 S7 的同一套数据）：

1. 对四个样品分别提取每个转速的极限电流 j_L，给出两组值：
   - 按现行口径，0.30 到 0.40 V 之间的中位数，不扣基线
   - 扣基线后的值，基线按 SI 定义取 1.00 到 1.05 V 的中位数
2. 画 j_L 对 ω^1/2（ω 用 rad s⁻¹），线性拟合，给出斜率、截距、R²。
3. 把拟合斜率与 Levich 理论斜率比较。理论斜率用 0.62·n·F·D^(2/3)·ν^(−1/6)·C，取 n = 4、F = 96485 C mol⁻¹、D = 1.9 × 10⁻⁵ cm² s⁻¹、ν = 0.01 cm² s⁻¹、C = 1.2 × 10⁻⁶ mol cm⁻³，并同时报告 D = 2.0 × 10⁻⁵、C = 1.26 × 10⁻⁶ 这一组的结果，说明理论值本身的范围。
4. 在 REPORT 中如实判断：扣基线后斜率是否落入理论范围，截距是否接近零。斜率正常加固定截距，说明是电容或背景电流；斜率本身偏高，说明是厚膜扰动扩散层。两种都不成立就如实写不能判定。

不改表 S3 的数值，不改任何图。结论只写进 REPORT，由 Claude 决定是否写入论文。

## 任务二：干净表面 ORR 数据，明确答复

T017 没有正面回答这个问题，现在只要一个明确结论。

对 FeCoMn–NC、FeCo–NC、Mn–NC 三个模型，在 IMR 和 Genkai 上检查是否存在：

1. **干净表面背景**：不含任何 H*、O*、OH* 预覆盖的弛豫结构（FeCoMn–NC 为 C174N4Fe27Co32Mn，FeCo–NC 为 C180Fe27Co32，Mn–NC 为 C174N4Mn）。
2. **干净表面上的 ORR 中间体**：上述背景各加 OOH*、O*、OH* 的弛豫结构。FeCoMn–NC 要分别检查吸附在 Mn 上和吸附在颗粒 Fe/Co 上两种情况。

对每一项，明确写存在或不存在。存在的给出机器、完整路径、原子数与组成、最后 sigma→0 能量、是否正常结束与离子收敛、计算设置是否与现行 S7 一致、CONTCAR 与 INCAR 的 SHA256。

设置一致且结构合格的，按 SI 2.5 节口径（G(H2) = −6.833 eV，G(H2O) = −14.327 eV，修正 O +0.066、OH +0.343、OOH +0.403 eV）和式 S13 到 S20 算出 ΔG_OOH*、ΔG_O*、ΔG_OH*、四步 ΔG、电位决定步、U_L、η，与现行表 S7 并列成一张表，并写明干净表面给出的 U_L 顺序与实验半波电位顺序（FeCoMn–NC 0.885 > FeCo–NC 0.864 > Mn–NC 0.840 V）是否一致。

缺项就明确写不存在，不要用相近体系、不同原子数或不同设置的结构替代，也不要自行提交补算。
