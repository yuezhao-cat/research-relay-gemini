## 建议查找方向（不限于此）
1. **同一 Mn 位点、轴向配体不同的系列**：现有输出中同一材料 Mn 上轴向为 无 / OH / O 的结构（如 Mn–NC 干净 vs Mn=O；FeCoMn–NC 各覆盖背景中 Mn 裸 / Mn–OH / Mn–O），以及这些背景上反位中间体的 ΔG、−ICOHP。若点数多于 2，给出轴向 −ICOHP（或键长）与反位 −ICOHP / ΔGOH* / ΔGOOH* 的对应表，看是否单调。
2. **共享轨道**：轴向与反位共用 Mn dz²。查现有轨道分辨 PDOS（SI 图 S28 来源）中两 Mn 位点覆盖背景的 dz² 占据、dz² 中心、费米面附近 dz² 态密度，Mn=O 与 Mn–OH 是否不同。
3. **自旋**：Mn 磁矩与反位结合在现有各态中的对应关系。
4. **结构**：Mn 出平面位移、Mn–N 键长（覆盖背景与吸附后）。
5. **电荷密度差**：现有 Δρ（如 S31 来源）中轴向与反位方向的电荷分布。
