## 0. 核心理念

用户需要的不是一套“AI 论文写作流程”，而是覆盖**文献调研→阅读→创新假说→实验/表征设计→实验与表征数据分析→可复现出图→DFT/超算设计执行与分析→整合实验计算证据→论文与审稿**的多智能体研究系统。

不应把模型能力永久绑定单一岗位。Claude/GPT/Gemini 都能科学推理，Claude Code/Codex/Antigravity 既能动手，也能进行科学推理。各自实际优势、所连接工具、任务上下文、额度/可用性随时变化，**能力重叠但不等同**；不能凭简单型号标签断定谁永远最强。

系统原则：

1. **能力共享**：任何模型都能提出科学假说与独立审稿建议；获授权且具备适当工具的模型可执行相应操作。
2. **动态调度**：按具体任务风险、工具可用性、所需上下文、模型可用额度及历史核验表现选择执行者和复核者。
3. **证据优先**：模型共识不能取代原始数据；高风险结论强制异人独立复核。
4. **研究连续性**：GitHub 保留工作状态、决定、输入输出与可复核路径；额度耗尽后可快速交接。
5. **用户主权**：赵月批准研究方向、核心解释、正式论文稿、新实验和昂贵超算操作。
6. **渐进实施**：保留现有 `research-relay` 和生效 `ROLES.md`；先提案、试运行、复盘，再授权修订。

## 一、八大科研工作模块

| 模块 | 主要任务 | 典型产出 | 关键质量门槛 |
| --- | --- | --- | --- |
| 1 科研情报 | 文献检索、逐篇原文阅读、趋势/竞争对手分析、综述/引文网络 | 带 DOI、原文页码/图号及可靠性评价的阅读报告 | 原文可追溯，不能只凭摘要/二手转述 |
| 2 创新机会 | 找研究空白、形成假说、竞争机制、新 idea、优先级 | HYPOTHESES、创新性及可证伪性矩阵 | 明确已知先例与可区分预测，不把换材料当创新 |
| 3 研究方案 | 材料/合成、反应条件、对照实验、operando/XAS/XPS/Raman/IR/DEMS/Mössbauer 等表征、DFT 方案 | 实验设计/表征任务单/计算方案及预算 | 明确对照、预期正反结果、可区分竞争假说的判据 |
| 4 实验与表征分析 | 电化学、谱学、显微、统计误差、峰拟合和数据质量 | 数据处理脚本、可复核结果表、异常/不确定性说明 | 保留原始文件；异人复核重要量 |
| 5 理论与超算 | 结构、吸附态、反应自由能、能垒、电子结构、收敛/磁态审计、作业准备和执行 | 参数冻结清单、作业/路径记录、原始输出索引、复核报告 | 参数/参照态/电子态可比；任务需赵月明确批准；不自动提交昂贵作业 |
| 6 图表与可视化 | 科学绘图、结构示意、结果可视化、图注/SI 对齐 | 可编辑矢量图+高分辨输出+重现脚本 | 数字同源、单位一致、避免选择性展示 |
| 7 证据整合 | 实验-理论交叉验证、因果机制、替代解释、核心创新点 | CLAIMS–EVIDENCE、争议/限制/拒绝的假说 | 证据层级清楚，不能把模型预测写作实验直接证实 |
| 8 写作传播 | 主文、SI、标题摘要、投稿定位、审稿回复、研究汇报 | 版本锁定的正式稿与核查表 | 一稿主笔、独立审查、赵月最终裁决 |

**科研不是单向流水线**：文献→假说→实验/计算→结果可以往复，科研方向允许证据驱动改写。模块之间可并行，但关键决策应设置关口。

## 二、三层架构

### A. 科学思考与论证层
Claude web、Claude web 2、GPT、Gemini，以及可承担推理任务的执行智能体，负责假说、替代解释、方案对照、叙事、原创性和独立评审。重要问题**先独立评价、后交叉讨论**。

### B. 科研执行与工具层
Claude Code 本地/云端、Codex、Antigravity（根据它们实际可操作的本地/云端文件、超算、代码/绘图和数据库）负责检索提取、脚本、数据复核、图件、计算作业及分析。**工具可达性和额度决定实际任务分配，而不是品牌标签**。

### C. GitHub 共享知识与调度层
`research-relay` 为权威仓库，保存任务队列、研究决定、讨论、证据表、输出索引、版本和交接。原始大型数据/OUTCAR/波函数/图像可在 OneDrive、超算或本地，GitHub 保存稳定位置、校验和、程序及可复核摘要，避免超大仓库。Gemini 镜像另行同步；**只读导入不等于实时刷新或具备写权限**。

## 三、按任务而非按 AI 固定岗位调度

| 任务条件 | 调度策略 |
| --- | --- |
| 格式/文献元数据整理等低风险、可逆任务 | 一名具备工具的模型完成；必要时抽查 |
| 常规实验/谱学处理、图文检查 | 一个执行，一个不同模型根据原始文件抽样或完整复核 |
| 关键 DFT、机制归因、反常数据 | 执行者 + 非执行者从原始证据独立复核；另由科学审稿方审竞争解释 |
| 新 idea 或重大路线选择 | 至少两条独立假说路径，核文献先例和可区分实验预测；赵月决定 |
| 某模型额度不足或不可用 | 使用拥有相应工具和能力的替补；承接任务记录，不重新读全部历史聊天 |
| 模型观点冲突 | 记录争论点、可检验证据、最小区分性验证；不可多数投票决定 |
| 正式论文/Word | 仍遵守现行 ROLES：Claude web 主笔、唯一正式 Word 修改者，除非赵月另行修订 |

关键原则：**固定的是责任、授权边界与核查标准；动态的是执行者、复核者和参与模型数量。**

## 四、风险等级与 Token / 额度管理

各模型可能存在 5 小时窗口及每周额度约束，但**不同服务限制会变化，不应假设每家完全一样**。模型须在任务开始时报告自己能否完成/预计交接，而不是编造剩余额度。优先把额度用于高信息增益的科研判断与关键复核。

- **L1 低风险**：单模型完成，保留来源；必要时抽查。
- **L2 中风险**：执行 + 独立复核，确保重要数字可复现。
- **L3 高风险**：核心论文结论、电子态、机理因果、重大实验/计算方案至少两条独立推理路径，并有跨模型/跨能力池原始证据审查，赵月裁决。
- **L3 不因额度紧张免除必要验证**：若无法完成，应将结论标为 pending/insufficient evidence，延后确认，而不是降级成已证实。
- **减少浪费**：一个任务一个明确问题；同一写作单元至多两轮常规审稿；主稿不由多模型反复并行全量重写；按争议点局部复核；使用短交接记录。
- **缓存成果**：文献抽取、对照数据、脚本、事实表一次生成多模型复用；复核时独立查看原始来源，避免只复读别人结论。

## 五、建议通用任务协议（Task Contract）

每项科研工作开任务单并包含：

```yaml
task_id: FeCoMn-TXXX
module: literature|idea|design|experiment|characterization|dft|figure|synthesis|writing
priority: P0|P1|P2
risk: L1|L2|L3
scientific_question: "待解决的可检验问题"
inputs: ["原始文件与版本/commit/路径"]
constraints: ["现行决定、禁止事项、预算与安全边界"]
success_criteria: ["可量化或可核查的完成条件"]
executor: "按能力/额度选定"
independent_reviewer: "不得与执行者相同"
approval_required: ["新实验|超算提交|正式稿改动|敏感数据公开"]
outputs: ["报告|脚本|图|事实记录"]
status: pending|doing|review|approved|blocked
handoff: "剩余工作、已处理文件、失败/异常与下一步"
```

每个 Task Contract 的 executor、reviewer 随时可由有权协调者按规则重派，但不得隐瞒原执行记录。

## 七、关键科研操作的审批与可复现性

- 设计实验/表征：必须给科学问题、对照、判别性预期、仪器与样品限制、潜在失败情形；执行前赵月批准；涉及危险化学品与实验室设备时走实际安全管理流程。
- 超算计算：先给模型、电子态/磁态、覆盖、参照、泛函/U/色散、k 点、截断、溶剂/电位处理、预计预算与停止条件；**未经赵月批准不能提交新计算、批量改作业、改参数或删原始文件**。
- 实验与理论数据：保留原始数据、处理脚本、版本和质量问题；数值复核独立于原产出者；不可用“多模型赞成”替代复现。
- 图件：每张图追踪脚本与输入；对应正文、SI 和图注终检。
- 外部操作：新增仓库可见性、共享/公开、发稿/投稿、发送邮件等需要相应授权，不能偷偷操作。
- 機理创新：先分析已有先例，再明确新贡献是反应态、因果对照、能量分解还是可推广原则；拒绝纯粹措辞包装。

## 八、FeCoMn 试点案例

以轴向 OH–Mn–N4 反位 ORR 中间体为例：
1. 已有 T032/T041/T042 说明固定模型内轴向 OH 的吸附能学及形变竞争。
2. 科学思考层提出竞争机制并检查 Wan 2022 等先例。
3. 执行层读取已有原始结果，独立验证基底形变与冻结相互作用贡献，严格区分静态电子能与自由能。
4. T039 已显示旧 0.47 V 颗粒抗过氧化叙事受到 Mn=O 电子态分支混杂，**不得恢复为已证实因果**。
5. 检查 operando 红外的峰重叠及谱学证据等级，不能把歧义峰当唯一直接证据。
6. 形成经过复核的 CLAIMS 与 FIGURE 对照，选定主线后正式写作；新实验/新计算只给方案，等待赵月授权。

## 十、结语

**要实现的是 AI 研究团队，而不是“七个固定岗位的聊天窗口”。**

赵月负责提出问题、评估科研价值并拍板；AI 团队负责高效地寻找证据、提出方案、动手执行、独立核查、整合机制和清楚表达。系统价值不取决于模型数量，而取决于**科研产出的可靠性、复现性、创新性与单位额度所产生的有效进展**。
