## 1. 数据来源与定义
- **几何**：本会话连不上超算。我用的是 T031 从原始 CONTCAR 读出、存在 `from_agent/FeCoMn-T031/{imr,genkai}_branches.json` 里的完整坐标、晶胞和元素表，在本地自己算高度，没有用任何报告里的高度值。
- **离面高度 h**：取离 Mn 最近的 4 个 N（最小镜像），做最小二乘平面，h 为 Mn 到该平面的有符号距离。**正方向朝反应中间体的反侧**，有轴向配体时即配体一侧；吸附前的结构沿用本组中间体所在的一侧。
- **ΔG、U_L**：由同一批 JSON 里的 σ→0 能量按 CHE 重算，G(H₂) = −6.83271509 eV，G(H₂O) = −14.32745679 eV，校正 0.403/0.066/0.343 eV。**与 T032 `original_ligand_free_energies.csv` 逐项一致（差 < 0.0001 eV）。**
- **高度的独立核对**：8O* 两组和 Mn–NC 轴向 O 组共 11 个态，与 T032 `selected_descriptors.csv`（取自同源静态）一致，差 < 0.001 Å。
- **缺口**：8O* 无配体组的吸附前结构 `FCM_rich8O_cont1` 不在 T031 JSON 里，它的 h 和由它算的 ΔG 用 T032 值（表中标出）。
- **FeCo–NC 不适用**：反应位在颗粒上，没有 Mn–N₄。

## 3. 规律是否成立

**成立的部分**
- **OOH***：h 从 −0.3 Å（无配体）到 ≈0（轴向 OH）再到 +0.17 Å（轴向 O），ΔG(OOH*) 依次为 3.9 → 4.1 → 4.7 eV，单调。
- **三组分得很开**：无配体时三种中间体都把 Mn 拉向自己 0.28–0.46 Å；带轴向 OH 时 OOH* 和 OH* 态的 Mn 回到平面（|h| ≤ 0.02 Å）；带轴向 O 时 Mn 留在 O 一侧（+0.13～+0.17 Å）。这和"拔河"图像一致，作为结构上的直观说明很好用。

**不成立的部分（反例）**
1. **同样回到平面，强弱可以差很多。** OH* 态：FeCoMn–NC 8O* + OH 的 h = −0.009 Å，ΔG(OH*) = 0.85 eV；Mn–NC + OH（假设态）的 h = −0.005 Å，ΔG(OH*) = 1.33 eV。位置几乎相同，ΔG 差 0.48 eV，U_L 差 0.21 V（0.78 vs 0.57）。
2. **O* 态不单调。** Mn–NC + O 的 O* 态 h = −0.007 Å（就在平面），ΔG(O*) 却最弱（2.39 eV）；Mn–NC + OH 的 O* 态 h = +0.142 Å，ΔG(O*) = 1.90 eV，反而更强。
3. 假设态按方案"单独标出、不计入结论"。但它是真实算出来的结构和能量，物理规律对它同样适用。把它剔除只是让反例看不见，审稿人如果拿同类数据检验，会得出同样的结论。

**混杂因素**
- 去掉假设态后，只剩三类点：无配体、OH、O。h 和"配体是什么"完全重合，数据无法区分"位置决定强弱"和"配体决定强弱，位置只是配体的结果"。
- 吸附后 Mn 停在哪里，本身是配体键和中间体键共同作用的结果，与吸附强度同时产生。它更像是指示量，不能说它决定了吸附强度。T041 的冻结几何拆分（形变贡献 0.24–0.43 eV）只说明形变能占一部分，不等于位置决定全部。

## 4. 结论与写法建议
- **不建议写"Mn 的位置决定吸附强弱"或"回到平面最优"。** 只有三类点，而且有两个同位置不同强弱的反例。
- **建议作为现象写，用来把"拔河"画面落到可测的结构量上**，放在图 6 的机理段：
  > Without an axial ligand, each intermediate pulls Mn 0.28–0.46 Å out of the N₄ plane toward itself; with the axial OH, Mn stays in the N₄ plane after OOH* or OH* adsorption.
  
  直译：没有轴向配体时，每种中间体都把 Mn 拉离 N₄ 平面 0.28–0.46 Å；带轴向 OH 时，吸附 OOH* 或 OH* 后 Mn 仍停在 N₄ 平面内。
- 这句只陈述数据，不加因果，与当前主线（配体从对侧削弱结合）不冲突，可以直接用。
