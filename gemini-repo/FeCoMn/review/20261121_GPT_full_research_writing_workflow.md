# 多 AI 科研写作工作流建议：科研课题组 + 期刊同行评审模式

**来源：GPT 与赵月讨论的完整工作流建议，2026-11-21。**

**状态：工作流建议，供各智能体阅读和讨论；尚未取代仓库现行 README 权限规则，最终以赵月决定为准。**

我认为，你现在最应该改变的，不是使用哪个 AI，而是**从“多个 AI 一起写论文”升级为“多个 AI 分工完成科研写作”**。

这次 FeCoMn–NC 摘要讨论已经暴露了一个问题：六个智能体反复修改同一段文字，虽然产生了很多有价值的意见，但也出现了版本混乱、重复讨论和相互迎合。

我建议建立一个类似**科研课题组 + 期刊同行评审**的工作流。

## 一、给每个 AI 分配固定职责

| 智能体 | 职责 | 主要任务 |
| --- | --- | --- |
| **Gemini 网页版** | 科学叙事设计 | 提炼创新点，提出不同论文故事和摘要结构 |
| **Claude web** | 主笔 | 撰写 Introduction、Results、Discussion、Abstract |
| **Claude web 2** | 语言编辑 | 检查段落逻辑、语言精度、衔接与冗余 |
| **Claude Code 云端** | 科学核查 | 检查 DFT、实验数据、计算口径及证据可靠性 |
| **Antigravity** | 图文一致性 | 检查图件、图注、正文与 SI 是否相互对应 |
| **GPT（我）** | 独立审稿人 | 质疑核心假说、寻找替代解释、判断创新性和证据边界 |
| **赵月** | 通讯作者 / 最终决策者 | 决定科学主张、实验需求、文章方向和最终版本 |

这不是说某个模型永远只能做一件事，而是**先设定责任归属，避免六个人同时当主笔**。

## 二、建立五阶段科研写作流程

### 1. 科学问题与证据锁定

Claude Code 核查数据，GPT 独立审查因果关系。

**产出：**哪些结论已证明、哪些属于模型推断、哪些暂时不能写。

### 2. 科学故事设计

Gemini 和 Claude web 各自独立提出一条主线，不提前阅读对方的写作方案。随后由 GPT 评估创新性与逻辑风险。

**产出：**2 个真正不同的科学故事，而不是 6 个措辞版本。

### 3. 正式撰写

赵月选择主线，Claude web 负责唯一的正文主稿。其他模型不直接修改主稿，只提交审阅意见。

**产出：**一个稳定的 manuscript draft。

### 4. 独立交叉审稿

GPT 审查科学逻辑，Claude Code 审查数据，Antigravity 审查图文一致性，Claude web 2 审查语言。

**产出：**按 Critical、Major、Minor 分类的审稿意见。

### 5. 修改、冻结与投稿

主笔逐条处理意见，赵月决定接受或拒绝。完成一轮后冻结版本，除关键科学错误外不再无限循环修改。

**产出：**经核查的投稿稿、SI 和最终图件。

## 三、GitHub 应该怎样组织？

建议沿用现有的 `research-relay` 仓库，在每篇论文下面固定建立这些目录：

```text
FeCoMn/
  evidence/       核实后的证据与数据索引
  story/          科学问题、创新点、逻辑主线
  manuscript/     唯一正式写作版本
  review/         各 AI 的独立审稿报告
  discussion/     争议、讨论和待解决问题
  DECISIONS.md    赵月的最终决定
  STATUS.md       当前版本、负责人、下一步
```

这里最重要的是 **DECISIONS.md**。

例如，在 FeCoMn 项目中记录：

- T039：电子态不一致，暂不用于证明颗粒抑制过氧化。
- T041/T042：作为轴向 OH 几何调控机制的主要依据。
- 摘要：采用工作态表面覆盖与 Mn–OH 吸附调控的主线。
- 不再开展未经批准的磁态分支搜索。

这样任何模型开始工作前，先读取决定记录，就不会不断推翻已经做出的选择。

## 四、三条必须执行的规则

### 规则一：先独立，后讨论

尤其是科学创新性评估。不要让所有模型先阅读 Claude 的判断，再各自表示同意。那样容易形成虚假的共识。

### 规则二：科学事实不能靠投票决定

六个 AI 都赞成某种机理，也不能代替原始数据。像 T039 这种问题，一个正确的反例就足以推翻五个模型的一致结论。

### 规则三：讨论必须有终点

每轮只解决明确的问题，例如“轴向 OH 削弱吸附的主要能量来源是什么”。

每个问题最多经历：独立意见 → 交叉审查 → 赵月作决定 → 关闭讨论。只有新证据才能重新开启。

## 五、最重要的建议

**把 AI 从“替你写文章的工具”，变成“帮助你形成、验证和表达科学判断的团队”。**

这需要赵月始终掌握三个权力：科学问题的定义权、证据是否充分的判断权、最终文章的决定权。

对于当前的 FeCoMn–NC，我建议下一步**不要继续让六个模型修改摘要**。先冻结现有摘要作为基准，开始逐图审查 Results and Discussion，检查每一段是否真正支撑摘要中的论点。

等正文科学逻辑稳定后，再由 Claude web 统一修改摘要，其他智能体只进行一轮交叉审查。

**这样才能让多个 AI 带来实质性的科研增益，而不只是制造更多版本。**
