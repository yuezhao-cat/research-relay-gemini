# 零成本实验锚点核查：XANES 与 SEIRAS 能否判定 Mn 工作态（Claude Code 云端，2026-11-20）

背景：Claude web 指出 13:36"低能分支不考虑"与 11-19"取已计算构型中最低"（`discussion/20261119_core_claims.md` 第 181 行）冲突，建议先用零成本实验数据判定。本文件核查现有数据能否做到。

## 1. Mn K 边 XANES：不能判定
- 只测了 FeCoMn–NC（正文图 2c），没有 Mn–NC 的 XAS，无法比较两种材料的 Mn 价态。
- 参比只有 Mn 箔与 MnPc，没有 Mn₂O₃、MnO₂ 等高价参比，边位置无法定价态。
- 非原位（制备态），不能回答工作电位下的状态。
- 仓库中无 XAS 原始数据（`data/origin_projects_from_user_20261114` 只有 4 个 .opju 的 SHA256）。
- 弱旁证：EXAFS 第一壳层 Mn–N/O 配位数 4.9 ± 0.6、平均键长 1.99 ± 0.04 Å（正文第 186–188 行），提示制备态 Mn 带一个轴向含氧配体；若含 1.58 Å 短 Mn=O，平均键长应约 1.88 Å，实测不像。单壳层拟合、非原位，只作旁证。

## 2. SEIRAS：可以区分两种分支，但需两个前提
预测（0.78 V 下 OH/O 偏好由表 S10 与 T031 换算）：

| 采用的 Mn=O | Mn 保持 Mn–OH 的电位上限 | 预测 OOH* 谱带（约 1215 cm⁻¹）起始电位 |
|---|---|---|
| 原采用（长键 1.655 Å） | 0.96 V | 约 0.9–1.0 V |
| 低能分支（短键 1.579 Å） | 约 0.51 V | 约 0.5 V |

前提：
1. 参比电极换算：文件名电位 −1 至 0.2 V，正文写 1.2 至 0 V vs RHE；README 明确未换算，需赵月提供参比电极或换算关系。
2. 谱带归属：OOH* 也可能来自颗粒位点，起始电位只作一致性检验。

数据：`data/SEIRAS_20241021_1`（21 个 CSV，695–2744 cm⁻¹，仅 FeCoMn–NC）。

## 3. 原位 XANES：赵月确认做不了（2026-11-20），不再考虑
剩下唯一的实验判据是 SEIRAS 起始电位（第 2 节）。

## 4. 建议
1. 赵月提供参比电极后，由 Claude Code 分析 SEIRAS 起始电位（零成本，约 1–2 小时）。
2. 起始约 0.9–1.0 V → 支持原采用图像；约 0.5 V → 按"取最低"规则改用短键态，主线随之调整。
3. 结果出来前，不把"颗粒推后过氧化 0.48 V"写进正文；图 6 段"OH 调吸附"部分可先写。
4. 若 SEIRAS 也判不了（参比不明或谱带归属不清）：不在正文写颗粒推后过氧化的定量结论；颗粒的作用只写到已有数据支持的程度（T038b：颗粒不改变裸 Mn 的电子结构；工作态 Mn 带轴向 OH），T039 两个分支的结果都放进 SI 如实交代。
