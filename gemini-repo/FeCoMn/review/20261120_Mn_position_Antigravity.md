## 一、独立提取口径与原子朝向核验说明（供与 Claude Code 互核）

1. **原始来源**：全部 **28 个**结构与能量直接从 IMR 与 Genkai 既有原采用分支优化目录的原始 `CONTCAR` 与 `OUTCAR` 读出（均已 `reached required accuracy`，不考虑低能分支，不提交新 DFT）。
2. **离面高度定义（严格执行统一符号规范）**：
   - 在最小镜像周期边界条件下，寻找 `Mn` 周围最近 4 个配位 `N` 原子，用 SVD 拟合 `4N` 最小二乘平面（表内 `N4_plane_rmsd` 均仅 `0.0000–0.0196 Å`，近似严格平面，与纯 `z` 差一致性 `< 0.001 Å`）。
   - **正方向统一朝向**：
     - 有轴向配体组（`MnNC_axO`、`FCM_clean_axOH`、`FCM_8O_axOH`、`MnNC_axOH`）：`n̂` 严格指向**轴向配体 `O` 所在一侧为正**（吸附后 `h < 0` 表示 `Mn` 被拉向反应中间体一侧，`h > 0` 表示留在轴向配体一侧）。
     - 无轴向配体组（`MnNC_bare`、`FCM_clean_bare`、`FCM_8O_bare`）：`n̂` 严格指向**反应中间体所在面的反侧为正**（吸附后 `h < 0` 表示 `Mn` 被反应中间体向反应侧拉出）。
   - **特别核查提醒（原子编号与 `±z` 翻转捕获）**：在提取原始 `CONTCAR` 时通过实测 `O–H` 与 `O–O` 键联发现，`FCM_clean_axOH`（`base` 与 `O*` 的轴向 `OH` 在 `-z`，`OOH*` 中轴向 `OH` 是 `O#241` 在 `-z`、而 `O#239-O#240-H#242` 为 `+z` 侧反应 `OOH*`）以及 `MnNC_axOH`（`OOH*` 轴向 `OH` 为 `O#182` 在 `-z`、`O*` 轴向 `OH` 为 `O#181` 在 `-z`）与 `FCM_8O_axOH` 的 `+z/-z` 朝向相反，若不按 `O–H/O–O` 键拓扑判断而直接按固定坐标方向取正负，会引发符号颠倒（尤其是 `±0.015 ~ ±0.020 Å` 与 `±0.142 ~ ±0.155 Å`）。本表与 CSV 已按真实配体拓扑逐构型校正。
3. **自由能口径**：直接从各原始优化 `OUTCAR` 读出 `energy(sigma->0)`，统一采用正文中性 CHE 参考（`G(H2) = -6.83271509 eV`, `G(H2O) = -14.32745679 eV`, `ZPE-TS(OOH*/O*/OH*) = 0.403 / 0.066 / 0.343 eV`, 四电子总自由能 `-4.92 eV`）。

## 三、规律检验结论（图 6 潜在核心亮点与科学边界）

对照交付图 [Antigravity_Mn_position.png](../from_agent/FeCoMn-T042_Mn_position/Antigravity_Mn_position.png)：

1. **核心假说在 6 组有效背景（18 个吸附态）上定量成立：**
   - **与自由能 `ΔG` 的正相关性**：吸附后 `Mn` 高度 `h_after` 与三个中间体吸附自由能全部呈单调正相关——线性拟合（`n = 6`）分别为 **`ΔG_OOH*`（`R² = 0.803`, 斜率 `+1.28 eV/Å`）**、**`ΔG_OH*`（`R² = 0.774`, 斜率 `+1.18 eV/Å`）** 与 **`ΔG_O*`（`R² = 0.982`, 斜率 `+2.56 eV/Å`）**。
   - **`O*` 为何不仅未破坏规律，反而线性最高（`R² = 0.982`）**：在对称的 `MnNC_axO + O*`（`O=Mn=O`，双侧 `1.660 vs 1.660 Å`）上，`Mn` 虽然停在平面 `−0.007 Å`，但这是因为 `O*` 的双键拉力整体强于 `OH*/OOH*`，把无配体/轴向 `OH`/轴向 `O` 三类体系的 `h_after(O*)` 集体向反应侧多拉偏移了约 `0.10–0.16 Å`（无轴向 `−0.37 ~ −0.41` → 轴向 `OH` `−0.10 ~ −0.15` → 轴向 `O` `−0.01 Å`），恰好仍与 `ΔG_O*`（`1.43 → 1.94/2.23 → 2.39 eV`）保持严格同序递增。
   - **与活性火山图 `$U_L$` 的对应**：`U_L` 对主导限速步的单键中间体位置 `h_after(OH*)` / `h_after(OOH*)` 呈现清晰的火山形分布——
     - **过强区（左支）**：无轴向配体，`Mn` 被拉向中间体 **`−0.28 ~ −0.46 Å`**，`ΔG_OH* = 0.47–0.58 eV`，`$U_L = 0.47–0.58\text{ V}$`（`OH*` 脱附中毒）；
     - **适中区（火山顶点）**：带轴向 `OH` 的 `FeCoMn–NC`（干净或 `8O*`），`Mn` 恰好回到 `N4` 平面（**`−0.009 ~ +0.015 Å`**），`ΔG_OH* = 0.81–0.85 eV`、`ΔG_OOH* = 4.12–4.14 eV`，**`$U_L = 0.78–0.80\text{ V}$`**；
     - **过弱区（右支）**：带轴向 `O` 的 `Mn–NC`，`Mn` 滞留在轴向 `O` 一侧 **`+0.13 ~ +0.17 Å`**，`ΔG_OOH* = 4.66 eV`，`$U_L = 0.26\text{ V}$`（`OOH*` 生成受阻）。

2. **与形变能（T041）的内在物理贯通**：
   - `Mn` 在吸附后的稳态位置 `h_after` 本质上反映了**轴向配体与反位中间体双向拉力的力学平衡点**：轴向单键 `OH` 与反位单键 `OH*/OOH*` 拉力相当，把原本离面 `+0.44 Å` 的 `Mn` 刚好拉回平面 `0.00 Å` 附近；同时这一回归平面过程付出了主导自由能削弱的几何重组代价（`OH* +0.24 eV`, `OOH* +0.43 eV`, `T041`），而平衡对称态未堵死 `dz²↑` 成键通道，从而同时锁定了“既不太强、也不太弱”。

3. **必须注明的边界条件（避免被审稿人抓偏）**：
   - 被排除的假设态 `MnNC_axOH` 在图上表现为明显离群点：虽然它几何上也停在平面附近（`OOH* +0.020 Å`, `OH* −0.005 Å`），但因 `OH*` 落入 `0.386 μB` 低自旋分支，`ΔG_OH*` 跳升至 `1.332 eV`（`$U_L = 0.570\text{ V}$`）。这说明**“回到 N4 平面”作为力学平衡与火山顶点的直观结构指标，成立的前提是在同一高自旋工作分支下比较；自旋态切换会额外改变结合能，不能仅靠几何位置脱离自旋做外推。**
