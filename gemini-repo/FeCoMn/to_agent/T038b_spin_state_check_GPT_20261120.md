# T038b 磁态一致性核查 — Claude Code 主查（2026-11-20）
**先核对，不重算；不修改正文/图。**

## 背景与已知数据
- A：clean FeCoMn–NC，Mn 局域磁矩 1.788 μB
- B：clean Mn–NC，Mn 局域磁矩 0.034 μB
- Ap：A 颗粒片段（无 Mn，不应要求其 Mn 磁矩）
- As：A 同几何切分的 Mn–NC 载体，Mn 局域磁矩 −0.034 μB
- C：FeCoMn–NC 颗粒 8O*、Mn 无轴向配体，Mn 3.116 μB
- C_support：C 同几何去颗粒，Mn 3.126 μB
- 原 MnNC_clean 母结构优化结束体系总磁矩 3.0306 μB；FCM clean 母结构总磁矩 139.1098 μB。**总磁矩不等于 Mn 局域磁矩**。
- B 静态 E≈−1661.286 eV，原母结构 E≈−1661.257 eV；B 可能收敛到另一磁态分支。A 与 As 之差既可能来自真正颗粒相关的稳定磁态变化，也可能来自自洽初值/不同局部解，当前不能判定。

## 本轮只核对并报告
1. 逐一给出 A、B、Ap、As 单点实际 INCAR 的 MAGMOM 全部关键设置（具体 Mn 值及相关 Fe/Co/N），以及是否读取 WAVECAR/CHGCAR（ISTART、ICHARG、ISPIN、LNONCOLLINEAR 等相关项）。Ap 不含 Mn，请注明不适用。
2. 读取 IMR 母结构 S_FeCoMnNC59_clean、MnNC_clean 的优化结束 OUTCAR：Mn 的**最终局域磁矩**，同时给出体系总磁矩；核查末步收敛、初始 MAGMOM。
3. 把 A vs As 的**同几何、初始磁矩与最终磁矩**并列报告，指出 A 是否沿用母结构所采用的磁态；B 的 0.034 μB 与原来高自旋体系的关系需标注（不能仅由总磁矩就武断等同于 Mn 局域磁矩）。
4. 在报告中标注：**核查前 A/As 的 Bader、Mn dz²、差分电荷 Δρ 暂不用于归因颗粒效应。** 当前可靠的同几何、同磁态对照仍是 C/C_support（Mn Bader +0.0061 e；dz² +0.0315 eV），仅适用于 8O*、Mn 无轴向配体模型。
5. **此轮不得自动重算**。若初始设置相同且 A 与母结构一致，但 A/As 最终磁态不同，再提出“每模型高/低自旋两初值、比较总能量”的最小可检验方案，等待用户决定。若设置不一致或 A 偏离母结构，明确列出不一致处和最小修正方案。

## 科学解释边界
不同最终磁矩不是自动的计算错误；不能强迫 A、As 同一磁态后把真实的稳定自旋态变化过滤掉。需要同时区分“固定磁态下的直接电子效应”与“分别稳定磁态的颗粒效应”。目前论文只主张 FeCo 颗粒共存改变工作态轴向配位偏好，以及该配位改变 Mn–OOH* 成键与 ORR 活性；不主张颗粒到 Mn 的直接电荷捐赠。完成后将证据路径和结论写入 T038b 的核查报告，并通知 Antigravity 独立复核。
