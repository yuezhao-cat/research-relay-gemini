## 需要查清的两件事

### 问题 1：已发表的颗粒或团簇 + 单原子 ORR 体系文献，是否只讨论了电子调控，没有讨论反应条件下单原子轴向配体？

具体说明：
- 本文中的参考文献 ref 7（Jiang 2016 JACS，Fe/Fe3C + Fe–Nx）和 ref 8（Huang 2022 Angew，金属团簇 + 单原子）是两个典型的颗粒+单原子 ORR 体系，它们支持"电子调控"的说法。
- 但我们需要更广泛地确认：**这类文献（颗粒/团簇 + 单原子，4e⁻ ORR）中，有没有人在工作条件下（有电位、有 KOH/H2SO4 电解液）讨论过单原子位点上的轴向 OH 或 O 吸附？**
- 如果没有，"此前忽略轴向配体"才能成立。
- 如果有，则需要确认那篇文章说的是"颗粒的存在会改变单原子的轴向配体"还是仅"单原子本身在工作条件下有轴向配体"（后者不影响我们的新颖性）。

**检索方法建议**：
1. 在 Zotero 本地库搜索包含 nanoparticle 或 cluster + single atom + axial 或 OH 的文献，优先查 ref 7、ref 8、ref 18（Cai 2022 Small）及相关引文中的全文。
2. 如有必要，联网查 2016–2024 年 Fe–N–C + 颗粒体系 ORR 文献（JACS, Angew, Nat. Catal., ACS Catal.），关键词：axial ligand / axial coordination / working state / operando / in situ + Fe-N-C / Fe/Fe3C + single atom / cluster。

---

### 问题 2：有没有人已经报道过"颗粒直接导致相邻单原子的轴向配体发生改变"？

具体说明：
- "单原子在工作电位下有轴向 OH 或 O" 已有大量文献（尤其是 Fe–N4 相关的原位 XAS 和 DFT 研究），这不是本文的新颖性。
- 本文新颖性的核心主张是：**颗粒（或其表面氧化状态）通过某种机制，改变了相邻单原子位点的轴向配体吸附状态**（例如颗粒上的 O* 覆盖度升高 → 相邻 Mn 单原子的轴向 OH* 稳定化）。
- 如果有文献已明确报道此机制，本文就不能称为首次发现，需要调整表述。

**检索方法建议**：
1. 在 Zotero 本地库中搜索含 particle / nanoparticle / cluster + axial / ligand / OH + single atom / Fe-N 的文献。
2. 在联网检索中查找：颗粒通过氧覆盖度（O* coverage）或工作态（working state）影响邻近单原子轴向配位的 DFT 或原位表征证据。
