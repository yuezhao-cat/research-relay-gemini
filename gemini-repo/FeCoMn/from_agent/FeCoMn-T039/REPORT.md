## 四、CHE 自由能与 `0.78 V vs RHE` 下配体相对稳定性（三组参考口径全核实）

按 SI 式 `(S4)–(S7)`：`G_form(U) = E_state − E_clean − N_O·G(H₂O) + ½m·G(H₂) + C_cov − m·eU`，其中 `Mn–OH*` 为 `N_O=1, N_H=1, m=1, C_cov(OH*)=0.343 eV`；`Mn=O*` 为 `N_O=1, N_H=0, m=2, C_cov(O*)=0.066 eV`（两者相减时 `E_clean` 与 `G(H₂O)` 严格消去）。反应 `Mn–OH* → Mn=O* + H⁺ + e⁻` 之 `ΔG_ox(U) = G(Mn=O) − G(Mn–OH) = [E(S_O) − E(S_OH)] + (0.066 − 0.343) + ½G(H₂) − eU`；任务书定义之 **`ΔG = G(Mn–OH) − G(Mn–O) = −ΔG_ox(U)`**。

### 1. 与 SI Table S10 覆盖度库严格同口径（`energy(sigma->0)` + 覆盖度库 `G(H₂) = −6.834 eV`, `G(H₂O) = −14.341 eV`, `E_clean = −1661.24918794 eV`）
- `ΔE(raw, σ→0) = E(S_O) − E(S_OH) = −1667.58789271 − (−1671.76396918) = +4.17608 eV`
- `U = 0 V`: `G_form(S_OH) = +0.7522 eV`，`G_form(S_O) = +1.2343 eV`；`ΔG(Mn–OH − Mn–O) = −0.4821 eV`（OH 更稳 `0.482 eV`）
- **`U = 0.78 V vs RHE`**: `G_form(S_OH) = −0.0278 eV`，`G_form(S_O) = −0.3257 eV`；**`ΔG = G(Mn–OH) − G(Mn–O) = +0.2979 eV ≈ +0.30 eV`**（即 **`Mn=O` 比 `Mn–OH` 稳定 `0.298 eV ≈ 0.30 eV`**）
- **转变电位 `U*`**：**`0.482 V vs RHE`**

### 2. 对照 `FeCoMn/review/T039_ClaudeCode.md` 的独立核查与 `0.0065 eV` 差异溯源

| 能量与参考气体口径 | `ΔE(S_O − S_OH)` (eV) | `ΔG(Mn=O − Mn–OH) @ 0.78 V` (eV) | `ΔG(Mn–OH − Mn–O) @ 0.78 V` (eV) | 转变电位 `U*` (V) |
|---|---:|---:|---:|---:|
| **Table S10 覆盖度同口径**（`E(σ→0)` + `G(H₂) = −6.834 eV`） | `+4.17608` | **`−0.2979`** | **`+0.2979`** | **`0.482`** |

**核查结论**：两方算例均确认 `0.78 V` 下配体偏好发生翻转；`0.2979 eV` 与 `T039_ClaudeCode.md` 所报 `0.2914 eV` 仅相差 `0.0065 eV`，来源完全透明：`0.00588 eV` 来自正文/SI Table S10 采用 `energy(sigma->0)`（已对照 `FCM_8O_MnOH` `E(σ→0) = −2140.1479 eV` 与 Table S10 `−2140.148 eV` 一致）而 `T039_ClaudeCode.md` 采用了 `TOTEN`（`F=`），另有 `0.00064 eV` 来自 ½ `G(H₂)`（`−6.834` vs `−6.83272 eV`）。
