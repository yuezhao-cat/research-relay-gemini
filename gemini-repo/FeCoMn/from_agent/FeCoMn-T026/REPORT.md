## 2. Mn 轴向 O / OH：覆盖度核查

在同一颗粒覆盖数下，按 SI 覆盖库口径 G(H₂)=−6.834 eV、OH/O 校正 0.343/0.066 eV，计算

`G(Mn–OH)−G(Mn–O) = E(Mn–OH)−E(Mn–O)−½G(H₂)+0.277+U_RHE`，其中 U_RHE=0.78 V。按 RHE 表示时不再另加 pH 项。负值表示指定的 OH 构型较指定的 O 构型稳定。8O 对的结果 −0.1802 eV 与 SI 表 S10 的 −14.92−(−14.74)≈−0.18 eV 一致。

**变号结论：已通过核查的 0、5、8 覆盖点均为负，没有观察到变号；2、4、6 点不合格，不能判断完整 0→8 序列何处变号，也不能声称全程不变号。**

补充边界：Mn–NC 指定的 `MnNC_O`（−1667.38075636 eV）不是 SI 表 S10 最稳的 Mn–O 构型；表中 `MnNC O bri` 为 −1667.742 eV。上表对照仅回答任务指定的 `MnNC_O` 对 `MnNC_OH` 两目录之差，不能用于判定 Mn–NC 全部候选构型的全局稳定轴向配体。
