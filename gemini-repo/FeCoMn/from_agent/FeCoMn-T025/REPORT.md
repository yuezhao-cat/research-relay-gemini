## 指定的两项比较与 FeCo–NC 缺项

- **B−C 的 UL 差值：无法按 T025 指定配对计算。** B 的指定背景未完成且组成错误；不能用它推断轴向 OH 的贡献。
- **C−现行覆盖态主结果：0.796−0.776 = +0.020 V。** 即按现有两组可比计算，C 组的 UL 比现行 8O*+Mn–OH* 模型高 0.020 V。此处只报告数值，不将其解释为实验因果效应。
- **FeCo–NC 的干净表面完整 ORR 三态：不存在。** T017 两台机器的全量目录清单中没有无预覆盖、对应 C180Fe27Co32 背景的 OOH*/O*/OH* 弛豫三态。IMR 有 `FCN_C_OH_mid`（C180Fe27Co32OH，碳位 OH*），但缺同一位点的 OOH* 与 O*；电子结构目录的 `FCN_OOH_full` 等是带 8O* 背景的静态后处理，不能代替干净表面 ORR 三态。

计算采用 SI 口径：G(H2)=−6.833、G(H2O)=−14.327 eV；O、OH、OOH 修正分别 +0.066、+0.343、+0.403 eV。四步按 O2→OOH*→O*→OH*→H2O；UL 为四步在 0 V 的负自由能变化中的最小值，η=1.23−UL。可复算脚本为 [calculate_t025.py](calculate_t025.py)。
