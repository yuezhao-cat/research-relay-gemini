# FeCoMn 项目协作规则

## 分工（2026-11-19 赵月更新）
| 角色 | 负责 | 不做 |
|---|---|---|
| Claude（网页版对话） | **所有论文文件的修改**：正文、SI、图注的 Word 文件，插入/替换图片，回复导师批注；写任务单（to_agent/）、方案文件（discussion/） | 不跑计算、不出图 |
| Claude Code | 与 Codex、Antigravity 同一类智能体：计算、出图、提取数据、交付报告（from_agent/）；核查其他智能体的数据，意见写入 review/ | **不修改正文、SI 的 Word 文件**，不改任务单与方案文件 |
| GPT 智能体（Codex） | 计算、出图、提取数据、交付报告（from_agent/）；核查其他智能体的数据 | 不修改 Word 文件，不改任务单要求 |
| Antigravity | 查找本地与超算现有数据、计算、出图；核查其他智能体的数据与 Claude 的结论，意见写入 review/ | 不修改 Word 文件，不下任务、不改他人文件 |
| ChatGPT（网页版） | 与 Claude（网页版）权限一致，可读可写仓库；Claude 为主要决策者；首要任务是核查 Claude 的工作。核查意见可直接写入 review/ 或讨论文件末尾；**修改其他任何文件须先经 Claude 同意** | 未经 Claude 同意不修改 review/ 以外的文件；不做计算与出图 |
| 赵月 | 最终决定 | |

说明：ChatGPT 可直接把意见写入 review/ 或讨论文件末尾（注明来源、日期、所读提交号）。要改其他文件时，先在 review/ 写“修改申请”（改哪个文件、改什么、理由），Claude 在同一文件里批复“同意／不同意”后才能动手；Claude 逐条回应意见并作决定，冲突时报赵月。Gemini 暂未接入。

Claude Code 虽然也叫 Claude，但在本项目中是智能体，和 Codex、Antigravity 职能相同。图做好后放在 from_agent/，由 Claude（网页版）插入 Word；智能体不要自己改 Word。

## 核查要求
- 核查必须读原始数据（OUTCAR、CONTCAR、INCAR、能量/磁矩/电荷），自己复算关键数字，不能只读 REPORT.md。
- 每条意见写明依据（文件路径、具体数值）。
- 文件名对应任务号，如 review/T031_review.md；正文文字核查用 review/MS_<日期>_review.md。

## 意见冲突
三方各自写明依据，由赵月决定。两方一致不等于正确。

## 仓库容量
只推文字文件（md、小 csv）。Word 文档仅在赵月明确要求时上传；大文件不推。

## 交叉核查（11-18 赵月定）
- **智能体三方互查（2026-11-19 赵月定）**：Codex、Claude Code、Antigravity 三个智能体的工作互相核查，谁做的由另外两方之一复核；默认分工（2026-11-19 14:03 赵月调整）：**Antigravity 主做，Claude Code 复核**；Codex 额度恢复后可分担主做，由 Claude Code 或 Antigravity 复核。临时由 Claude Code 主做的任务，改由 Antigravity 复核。复核必须打开原始文件或文献原文，不能凭记忆或只读报告。复核意见写入 review/，并在 STATUS.md 对应任务行注明复核方与结论。
- **数据：智能体之间相互核查（Codex、Antigravity、Claude Code 任意两方）。** 任一方给出的数值，由另一方从原始文件复读（路径、键编号、原子编号、结构与原采用分支是否一致、计算设置是否可比），结果写入 review/。
- **论证：** Claude（网页版）写的结论，由任一智能体对照数据查是否说过头。
- **推理：** 智能体的报告与建议，由 Claude（网页版）检查逻辑。
- **自做自查不算核查**：谁出的图或数据，必须由另一个智能体复核。
- **冲突：** 各写依据，赵月决定。

## 版本与文件
- 每份意见、报告开头注明所读的提交号；开始前先 git pull。
- 一个文件只由一方修改：方案文件（discussion/）Claude 写；核查意见 review/；数据报告 from_agent/；任务单 to_agent/ 由 Claude 写。

## 参考文献编号（2026-11-19 赵月，导师要求）
- 参考文献按正文首次出现的先后顺序编号，从小到大；同一处合引按升序排列。除非确有特殊情况，尽量不出现跳号或倒序。
- 前言改写期间先用现有编号占位，全文定稿后统一重排编号并检查有无孤立文献。
