# 顶刊的连贯证据链（从四方文献调研中提炼）与我们对照

## 一、八条范例链

1. **Wang, Tang, Zhou, JACS 2019（Fe(OH)N4 自我调节）**
   裸 FeN4 算出的电位与实验不符 → 微动力学算全电位窗口覆盖度，0.28–1.00 V Fe 始终带 OH* → 用 Fe(OH)N4 代替裸 FeN4 重算四步自由能，理论半波电位收敛到约 0.88 V，与实验对上 → 用分电流排除解离路径 → 结论：工作态配体自我调节。

2. **Zhao 等, Nat. Catal. 2025（高自旋 OH–Fe³⁺N4 为活性中心，10.1038/s41929-025-01324-7）**
   用结构明确的分子模型解决热解样品结构混杂（TOF 提高 76 倍）→ 磁性测试 + 原位红外锁定高自旋 Fe³⁺(S=5/2)–OH → 计算显示该态 OH* 吸附不强不弱 → 活性与 S=5/2 含量线性正相关，定性到定量闭环。

3. **Yang 等, Nat. Commun. 2021（相邻 Mn–N 改变 Fe 自旋，10.1038/s41467-021-21919-5）**
   对比 Fe–N–C 与 Fe,Mn/N–C 的活性差 → 磁化率实测证明邻位 Mn–N 改变了 Fe(III) 的自旋 → DFT 确定中自旋（单个 eg 电子）最利于与 O2 成键 → 与性能提升串联。**（邻位调节单原子状态，与我们"颗粒调节 Mn"同构）**

4. **Perutz 血红蛋白（Annu. Rev. 1998 等）+ Collman 模型化合物（1978）**
   T 态与 R 态晶体结构对比，Fe 离面位置不同 → 结合 O2 需要 Fe 进入平面 → 近端组氨酸的张力阻碍这一移动，亲和力降低 → EPR、共振拉曼、NMR 证实张力存在 → 模型化合物只换轴向碱（位阻碱）亲和力就下降，单变量验证。

5. **Jin 等, Nat. Catal. 2021（位点间距效应，s41929-021-00650-w）**
   控制相邻 Fe–N4 间距 → 本征活性随间距变化（< 约 1.2 nm 增强，约 0.7 nm 以下略降）→ DFT 解释相互作用改变电子结构。**单变量（距离）连续可调。**

6. **Wang 等, Nat. Commun. 2024（纳米曲率电场，10.1038/s41467-024-46175-1）**
   控制曲率 → 原位 Raman Stark 位移直接测电场，曲率越大场越强 → 活性随电场变化 → DFT 加场解释（电场按偶极/极化率作用，独立于标度关系）→ 推广到多种 SAC 和反应。**中介物理量被直接测出来。**

7. **Zitolo, Jaouen 等, Nat. Commun. 2017（Co–N–C vs Fe–N–C 工况 XAS）**
   制备无颗粒的 Co–N–C 与同法 Fe–N–C → 0–1.0 V 原位 XAS：Co 谱线不随电位变，Fe 价态/配位明显变 → 结合 DFT 说明不同金属在工作电位下轴向物种不同。**工作态由原位实验直接看到。**

8. **Houk 形变/相互作用（activation strain）**
   把能量拆成形变 + 相互作用 → 一系列体系中相互作用几乎不变、形变与能垒同步变化 → 结论"形变控制" → 直接展示 FMO 能隙与能垒不相关，排除轨道解释。

## 二、它们共有的六步
1. 先指出传统静态模型解释不了（与实验不符）。
2. 确定真实工作态（计算 + 原位实验两条腿）。
3. 只改一个变量的对照（模型分子、距离、曲率、轴向碱）。
4. **把中介物理量直接测出来**（磁化率测自旋、Stark 测电场、XAS 测价态/几何）。
5. 定量关联（活性随该量连续变化，最好线性）。
6. 排除其他解释（展示别的量不相关）。

## 三、我们对照这六步
| 步 | 我们现有 | 缺 |
|---|---|---|
| 1 静态模型不行 | 有：裸位点/初始结构解释不了，覆盖度后才对上 | 写清楚 |
| 2 工作态 | 计算有（覆盖度）；实验只有 SEIRAS 测到 OOH* | **缺原位实验看到 Mn 带 OH（XANES 价态、CV 峰位、SEIRAS 起始电位）** |
| 3 单变量对照 | T039（去颗粒）在跑；T041 固定配体拆分 | 只有一个点；**可借鉴 #5 做颗粒–Mn 距离扫描** |
| 4 中介量直接测 | 无。机理全靠计算 | **最大缺口**：Mn 价态/自旋/离面位移任何一个的实验测量 |
| 5 定量关联 | T042 三类点；T032 三档 | 点太少；可借 #2 做"活性 vs 某量"（如不同 Mn/Fe 比、不同颗粒含量样品） |
| 6 排除其他 | T038 排除"颗粒向 Mn 转移电荷" | 电场、刚度、载体几何三者未区分（[CC-6]） |

## 四、结论
顶刊之所以"连贯"，是因为每一步都有一个直接证据，而且至少有一个中介量被实验测出来、并与活性定量关联。我们目前计算链条较全，但第 2、4、5 步缺实验或缺连续变量，第 6 步缺排除。下一步优先：(a) 用已有 XANES/CV/SEIRAS 补第 2、4 步（0 成本，见 [CC-4][CW2-11]）；(b) T039 + 距离扫描补第 3 步；(c) [CC-6] 互斥计算补第 6 步；(d) 若有不同颗粒含量的样品，做活性与 Mn 状态的定量关联补第 5 步。
