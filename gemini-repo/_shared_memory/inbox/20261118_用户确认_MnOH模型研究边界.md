# 用户确认：研究边界设在选定Mn–OH模型

2026-11-18，赵月明确说明：8O背景中已知Mn–O候选比Mn–OH低约0.267eV，此结果此前已知；当时决定不再沿更低能搜索继续扩展，研究边界设在Mn–OH，到此为止。

这是当前范围决定，覆盖此前由“还可能有更低能磁态”推导出的继续扩展建议。后续围绕选定8O*+轴向Mn–OH模型分析ORR及颗粒/配体作用，不因该已知Mn–O候选自动切换背景、重定题目或追加更低能构型/磁态搜索。T031尚缺的第二起始等不自动转成新提交计算。

已有Mn–O与其他低能结果及审计记录原样保留，不删除、不改写能量。范围截止不等于证明Mn–OH为全局最低态、唯一实际反应状态，写作中应明确所分析的结构模型，不再用旧−0.18eV声称OH相对全部已知候选最稳定。图6a原“颗粒使OH最稳定”表述应重新判断是否适用；不因此自行改图或Word。

同样，选定OH模型也不预设颗粒只通过OH影响Mn；固定配体时的颗粒影响与配体影响分别依据已有匹配数据分析。
