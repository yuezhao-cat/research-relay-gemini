# FeCoMn T026：B 组与覆盖度核查（2026-11-17）

详见 `FeCoMn/from_agent/FeCoMn-T026/REPORT.md` 和 manifest.csv。以下是重写引言和定题目时必须遵守的证据边界。

- B 组以组成、晶胞、关键 INCAR、固定原子数匹配且收敛的 `S_FeCoMnNC59_clean` 为背景，得 U_L=0.4669 V，η=0.7631 V，限制步为 OH* 脱除。
- B−C 的 U_L 差值为 −0.3296 V；B−D 为 −0.1165 V。干净模型中的 FeCoMn–NC 与 Mn–NC 并非数值相同，不要写成“完全分不出”。
- 指定的 0、5、8 颗粒 O 覆盖点，`G(Mn–OH)−G(Mn–O)` 分别为 −0.2078、−0.1820、−0.1802 eV；都偏向指定的 Mn–OH 构型。**已核查点未出现变号，不能说“随 O 覆盖由 Mn–O 转为 Mn–OH”。**
- 标作“2”的两个目录实际为颗粒 0O、Mn 2O/2OH，且相差 2H、未收敛；4O 的 Mn–OH 未离子收敛；6O 的 Mn–OH 未正常结束。它们不能用于该系列的自由能差。完整序列尚未建立。
- 指定的 Mn–NC `MnNC_O` 对 `MnNC_OH` 差值为 −0.0656 eV，但 `MnNC_O` 不是 SI 表 S10 中最稳的 O 构型；另有 `MnNC O bri` 更稳。不要把指定两目录之差当作 Mn–NC 全局配体排序。
- T025 先前已确认：有轴向 OH 的干净颗粒 C 组 U_L=0.7965 V，与现行 8O*+Mn–OH 的 U_L=0.776 V 只差 0.020 V。**不能写颗粒 O 覆盖直接调控 Mn 位中间体结合强度。**
- 因此，引言里“表征干态与工作态不同”的问题意识可以保留；但“覆盖度改变轴向配体”的具体机制目前不能作为已证实结论。正文、题目要等待结构与自由能的进一步核查。
