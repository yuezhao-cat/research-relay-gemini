## 总纲：围绕三个核心问题的证据强度总表

1. **问题 1（为什么主样品 `FeCoMn–NC` 性能好？）—— 热力学与位点识别已充分证实**
   - `0.78 V vs RHE` 工作态为 `8O*` 颗粒 + 单齿 `Mn–OH`（`Table S7/S8/S10`、`T017`）：`ΔG_OOH* = 4.14 eV`、`ΔG_O* = 2.23 eV`、`ΔG_OH* = 0.85 eV`，**$U_L = 0.78\text{ V}$（`0.776 V`）**，限速步 `O₂ → OOH*` 在 `0.78 V` 仅上坡 `< 0.01 eV`，其余三步含 `OH*` 脱除（`−0.07 eV`）全下坡；避开了 `FeCo–NC` 颗粒多齿过强吸附（`U_L = 0.34 V`，`O* → OH*` 受限）与 `Mn–NC` `Mn=O` 削弱过头（`U_L = 0.26 V`，`O₂ → OOH*` 受限），与实验 `E_1/2 = 0.885 V` 及原位 IR 检出 `OOH*` 一致。
2. **问题 2 / 为什么 1（颗粒起到什么作用 / 颗粒如何使 `Mn` 带 `OH` 而非 `O`？）—— “不改裸 Mn 与不改带 OH 后的静态电子态”已证实；“翻转本身是否成立”正由 `T039` 判决**
   - 已证实颗粒几乎不改变**裸 `Mn`**（`T038/T038b`）以及**已带轴向 `OH` 态的 `Mn–N4–OH`**（本轮从 Genkai `FCMnew_base_full` vs `FCMnew_base_support` 新提取）。
   - **重要结构线索（原采用分支内部，IMR 既有优化几何）**：在原采用分支下，带 `8O*` 颗粒的 `FCM_8O_MnOH` 轴向 `Mn–O` 键长（`1.8772 Å`, `h = +0.4418 Å`）与无颗粒 `MnNC_OH`（`1.8788 Å`, `h = +0.4239 Å`）几乎完全一致；而 **`FCM_8O_MnO`（`Mn–O = 1.6545 Å`, `h = +0.3552 Å`, `tot_mag = 139.8243 μB`）则比无颗粒 `MnNC_O_bri`（`1.5771 Å`, `h = +0.5062 Å`, `tot_mag = 0.0091 μB`）显著拉长 `+0.0774 Å` 且体系保留较高自旋**。`T039` 正在同采用分支下检验去颗粒后是否翻转为 `O` 更稳。
3. **问题 3 / 为什么 2（轴向 `OH` 如何使 `Mn` 反应位点吸附适中？）—— 热力学结果已证实；本轮直接通过超算已有静态揭示出“几何重组占 `OH*` 削弱的 70%”，并纠正一处致命数量级误读**
   - 在同一 `8O*` 颗粒背景下，无 `OH` → 有 `OH` 使 `U_L` 从 `0.516 V`（`OH*` 脱附中毒）升至 `0.776 V`（`ΔG_OH*` 上移 `+0.333 eV`，`ΔG_OOH*` 上移 `+0.206 eV`，`T032`）。
   - 本轮从 Genkai 既有片断静态（`full / substrate / adsorbate`）直接拆出：`OH*` 削弱（`+0.3358 eV`）中 **70.4%（`+0.2363 eV`）来自 `Mn` 由 `+0.442 Å` 被拉回平面造成的基底形变能代价**，29.6%（`+0.0995 eV`）来自冻结几何电子结合减弱；与此同时，单键轴向 `OH` 保留了高自旋并在 `E_F` 附近推出单占 `dz²↑` 态，保证 `OOH*` 不像 `Mn=O` 双键那样被电子端砍塌。

### A2. 直接利用 Genkai 既有片段静态实现 `为什么 2` 的首次定量能量分解（0 新增 DFT）

Genkai `FeCoMn_electronic_20261023` 与 `FeCoMn_MnOH_electronic_v2_20261031` 中，**已存在 `full`、`substrate`（吸附终态骨架去吸附物后固定几何静态）与 `adsorbate` 片段静态**（均同为 `ENCUT=500, PREC=Accurate, EDIFF=1E-6, IVDW=12`）。直接提取 `energy(sigma->0)` 后：
- `E_distort = E(substrate) − E(base_full)`：吸附导致基底与颗粒发生几何重排的变形能代价；
- `E_bind_frozen = E(full) − E(substrate) − E(adsorbate)`：冻结在吸附终态几何下的纯电子结合强度；
- `ΔE_tot = E_distort + E_bind_frozen`。

| 体系与中间体 | `ΔE_tot` / eV | 基底变形代价 `E_distort` / eV | 冻结几何电子结合 `E_bind_frozen` / eV | 备注 |

| `8O_noOH` + `OH*` | `-3.2040` | **`+0.4349`** | **`-3.6389`** | Genkai 三片段全齐 |

**原子位移核实（`FCMnew_base_full` → `FCMnew_OH_substrate` POSCAR）：**
- `FeCo` 颗粒几乎未动（`rms = 0.0050 Å`, `max = 0.0157 Å`），`8O`（`rms = 0.0111 Å`），`4N`（`rms = 0.0327 Å`），唯独 **`Mn`（`0.4662 Å`）和轴向 `OH`（`O 0.4730 Å, H 0.5106 Å`）整体从 `h = +0.4418 Å` 被压回 `−0.0093 Å` 平面内**，同时轴向 `Mn–O` 键长维持 `1.8772 → 1.8759 Å`（基底内五配位锥形构型被迫改为六配位平面构型）。
- **这直接解开了 `T032` 的反例困惑**：为何加轴向 `OH` 后反位 `Mn–OH*` 局域 `−ICOHP` 反增（`2.70 → 3.06 eV`）而净自由能变弱 `+0.33 eV`？因为终态电子键本身几乎没变弱（仅差 `0.10 eV` 甚至共价轨道重叠略增），真正的削弱主要（70%）来自**把已被轴向 `OH` 拉出平面 `+0.44 Å` 的五配位 `Mn` 重新压回 `N4` 平面所需的几何-晶体场重组代价（`+0.236 eV`）**。
