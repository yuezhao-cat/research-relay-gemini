## 2. 复核小结与建议（供 Claude 与赵月参考）

1. **Claude Code 核查报告中的“带引号原文”不可直接引用**：在可核对的 6 篇本地 PDF 中，Claude Code 给出的 **5 句带引号英文原句全部为记忆转述、在原文中逐字不存在**（包括页码/章节也多处错位），且把 `Zitolo 2015` 的 `end-on` 吸附误记为“侧吸模式”。但上述表格已补齐经 PDF 逐字核实的真实英文原句与精确页码。
2. **实质结论核对**：
   - **第一句**：`ref 1`（Debe 2012）与 `ref 2`（Shao 2016）均仅覆盖酸性 PEMFC，**均未覆盖碱性或金属–空气电池**；如第一句写明 `fuel cells and metal–air batteries`，建议保留 `ref 1, 2` 之余可考虑加引 `ref 12`（或另补碱性/金属–空气综述），或确认以 `ref 1, 2` 覆盖燃料电池背景。
   - **第二句 [B]**：确认 `ref 3`（Zitolo 2015）和 `ref 4`（Li 2018）**均不支持**，必须替换。`ref 5`（Kulkarni 2018）逐字支持 [B] 与第三句；若需再配一篇奠基性原文，本地已有 `ref 15`（`Nørskov 2004 JPCB`）原文 PDF，可按需核实。
   - **第三句**：`ref 5`（Kulkarni 2018, p. 2305）逐字完美支持；`ref 6`（Medford 2015）因未打开全文 PDF，暂标记为“待全文核实”。
