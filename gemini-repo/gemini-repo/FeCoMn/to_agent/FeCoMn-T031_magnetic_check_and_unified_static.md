# FeCoMn-T031 磁态核查 + 统一静态（优先第 1 项）

背景：T030 与 Bader 结果显示，无轴向 OH 时 Mn 磁矩在 OH* 态由 +3.12 翻为 −3.19 μB，O* 为 −0.51；有轴向 OH 时 OH* +2.45、O* +0.37。有无 OH 的 ΔG 差可能混入磁态差异。正文核心结论（ΔGOH* 0.52→0.85 eV，η 0.71→0.45 V）依赖这些能量，须先确认。

## 1. 磁态核查（决定正文数字能否使用，优先）
范围：2×2 共 16 个结构
- 背景：Mn–NC 无 OH、Mn–NC 加轴向 OH、FeCoMn–NC 无 OH、FeCoMn–NC 加轴向 OH（干净颗粒）
- 另加正文主线 8O* FeCoMn–NC 有/无轴向 OH 两组
- 每组：Covered、OOH*、O*、OH*

要求：
- 每个态至少两种初始磁矩（Mn 与颗粒平行 / 反平行），报各自能量与 Mn、颗粒总磁矩。
- 重点：无 OH 的 O*、OH*；有 OH 的 O*（现有两个分支不一致）。
- 如最低能态与现用结构不同，重算 ΔG(OOH*/O*/OH*)、U_L、η、限制步，列新旧对照表。
- 结论只报数据，不改图、不改 Word。
