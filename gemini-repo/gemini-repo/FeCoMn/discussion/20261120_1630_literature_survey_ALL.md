## 17:10 赵月：文献调研的核心目标（最高优先级）
我们一直围绕"适中"，但解释不清**为什么适中**、**为什么 Mn 被拉回平面就适中**。请各方查文献，专门找"没点透的方向"：
1. 顶刊里别人怎样从机理上解释"适中/接近火山顶"——不是"比对照强/弱"这种比较，而是用什么物理量、什么推理链说明某位点的吸附**恰好**落在最优值。重点记录他们的证据和推导顺序。
2. 有没有人解释过"配体/环境引入的能量代价（形变能、重组能、反位效应、电子推拉）的**大小**为什么恰好抵消吸附过强的部分"，以及怎样论证这种"恰好"不是巧合（例如系列配体、连续可调的参数、标度关系下的解析式）。
3. 金属离面位移、配位几何柔性与吸附强度的关系：别人怎么从几何推到能量、再推到活性；有没有把"金属回到平面"与最优吸附联系起来的。
4. 分子催化（卟啉、酞菁、血红素、细胞色素 c 氧化酶）中轴向配体"调到刚好"的经典解释（push effect、trans effect、spin crossover、out-of-plane displacement），能否迁移到单原子。

## Claude web 的一个候选解释（请文献与数据一起检验，指出漏洞）
- 火山顶点：ΔG_OOH* − ΔG_OH* ≈ 3.30 eV ⇒ 最优 ΔG_OH* ≈ (4.92 − 3.30)/2 ≈ 0.81 eV。
- 裸 Mn ΔG_OH* = 0.52 eV，比最优强约 0.29 eV；带 OH 0.85 eV（差 0.04）；Mn–NC 带 O 1.45 eV（弱 0.64）。
- OH 的削弱主要是形变代价：中间体须把 Mn 从 OH 一侧拉回平面，形变代价 0.43 → 0.67 eV（多 0.24 eV，OH*；OOH* 多 0.43 eV）。
- 候选说法：轴向配体收取的形变代价随其对 Mn 的拉力增大；单键 OH 收的代价（约 0.3 eV）恰好抵消裸 Mn 多出的吸附；双键 O 收得太多。Mn 停在平面只是"恰好抵消"的结构表现。
- 已知弱点：只有三类点；"恰好"可能是巧合；Mn 位置与配体类型重合（Claude Code 云端指出）。请找文献里怎样处理这类问题。
