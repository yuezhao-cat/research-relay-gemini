# 共享记忆中转

Claude 不能直接写入 `D:\AI-Shared-Memory`（共享记忆）。需要存入共享记忆的内容，由 Claude 写到这里，再由智能体同步到本地。

## 流程
1. Claude 把待存内容写成一个文件，放在 `_shared_memory/inbox/`，文件名为 `YYYYMMDD_HHMM_项目_主题.md`。
2. 智能体收到"有新记忆"后：
   - 读取 inbox 里的文件，按内容合并进 `D:\AI-Shared-Memory` 中对应项目的记忆文件。
   - **只追加或更新对应条目，不删除已有记忆**。与已有记忆冲突时，两条都保留，并标注日期和来源，在 REPORT 里列出冲突，由赵月决定。
   - 合并完成后，把文件从 `inbox/` 移到 `synced/`（git mv），并在文件末尾追加一行：`已同步：日期时间，写入的本地文件路径`。
3. 反方向：Claude 需要读取共享记忆中的某部分时，会在 `to_agent/` 下发任务，智能体把相关内容摘录到 `_shared_memory/excerpts/`。

## 写入原则
- 只写赵月明确说过或明确确认过的决定和事实，不写推测。
- 每条注明日期。
- 不写密码、账号凭据、证件号、银行卡号。
