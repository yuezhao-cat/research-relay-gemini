# FeCoMn–NC 论文：2026-11-20 决定（摘要机理、T039 兜底、原位数据核查）

来源：赵月与 Claude Code（云端）的对话，以及赵月转发并认可的 Claude web / Antigravity 结论。只记赵月说过或确认的；未定事项单列。

## 已确认的决定
1. **原位 Mn K 边 XANES 做不了**（赵月原话："原位K 边 XANES不用想 做不了"），不再提。
2. **SEIRAS 判不了 Mn=O 用哪个电子态分支**：OOH* 谱带（约 1215 cm⁻¹）在 0.92→0.82 V 增长最明显，但 1.12/1.02 V 已有信号，与 Nafion C–F 重叠，也分不清来自 Mn 还是颗粒/碳。只能说对现用长键态略有利。
3. **SEIRAS 电位口径**：原始文件名为 vs SCE；E(RHE) = E(SCE) + 1.016 V；`-11.CSV` 是重测的 −1.0 V vs SCE（→ 0 V vs RHE）。定稿图 4（T015 20261116，1.2 → 0 V）正确，无需改图。+1.011 V 与 −1.1 V 是作废旧脚本口径。
4. **兜底写法（赵月提出并采纳）**：
   - 正文不写"颗粒推后过氧化 0.48 V"的定量结论；
   - 颗粒的作用只写数据撑得住的：拿掉颗粒后裸 Mn 电子结构几乎不变（T038b）；工作电位下 Mn 带轴向 OH；颗粒作用作为观察陈述，不展开机理；
   - 主线：工作电位下 FeCoMn–NC 的 Mn 带轴向 OH，这个 OH 把原本过强的吸附调到适中，所以活性最高；
   - 图 6 段"OH 怎样调吸附"不受影响，可以先写。
5. **摘要机理写法原则（赵月）**："比另外两个适中"是结论不是解释；解释要回答 FeCoMn–NC 自己为什么适中。摘要先解释、再得结论（适中 → 火山顶 → 活性最高）。Mn–NC 和 FeCo–NC 的对比不放摘要。
6. **摘要当前底稿**（赵月"目前最满意的一版"，但赵月认为机理部分不行，待改）：开头保留"Metal particles are very common…"两句；"species adsorbed on the catalyst surface change with potential, so the ORR takes place on a covered surface rather than a bare one. We therefore calculated the surface coverage at different potentials. At 0.78 V, … the adjacent Mn single atoms carry an axial OH. The ORR intermediates bind to these Mn single atoms opposite the axial OH." 末句与前句"适中"重复，待改。

## 待赵月决定
- 摘要机理句：Claude Code 建议弃用"弱 Mn–OH → dz² 靠近费米能级"（与 T041 矛盾：加 OH 后电子相互作用几乎不变，削弱主要来自形变；dz² 中心 −3.17 eV 不算靠近费米能级），改为形变机理句（OH 把 Mn 拉到自己一侧 → 对侧吸附须拉回平面 → 形变能抵消部分成键 → OOH* 仍能生成、OH* 不再过牢）。见 `FeCoMn/review/20261120_abstract_mechanism_v2_ClaudeCode_cloud.md`。
- 摘要末句：Claude Code 建议不等 T039，改为"必须考虑工作条件下单原子上形成的配体，而不是裸单原子"。
- T039 是否进 SI：Claude web 建议不放；Claude Code 建议不单独放 T039，但 SI 放 Mn=O 两电子态分支小表（因主线"工作电位 Mn 带 OH"也依赖该选择）。
- 标题：现标题"FeCo Particles Determine the Axial Ligand"与兜底写法冲突，候选 "Operating-State Axial Hydroxyl Ligation Balances Intermediate Binding at Mn Sites for Oxygen Reduction"。

## 已知风险（记录，未决）
- 主线起点"0.78 V 下 Mn 带轴向 OH"依赖 Mn=O 电子态选择：两配体都取最低能分支时，Mn=O 比 Mn–OH 稳定约 0.27 eV。
- 同一轴向 OH 放在无颗粒 Mn–NC 上（假设构型）U_L 仅 0.57 V，摘要不能泛化为"任何 Mn 带 OH 都适中"。
- Wan et al., Nat. Commun. 2022（10.1038/s41467-022-30702-z）已报道团簇诱导轴向 OH，前言须引用并区分。
